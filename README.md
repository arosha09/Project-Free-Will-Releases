# Project Free-Will Downloads

Official game builds, incremental updates and repair data are published under [Releases](https://github.com/arosha09/Project-Free-Will-Releases/releases).

- **First installation:** download and extract the Windows game package from the selected release.
- **Updates:** choose **Settings > Updates > Check for Updates**. The updater handles download, installation and restarting.
- **Repair:** use **Repair** if an update fails, or download **Project-Free-Will-Updater.exe** when the game cannot open.
- **Dev builds:** releases tagged `/Dev` are development previews. Official versions have tags such as `v1.0.0`.

The game checks for update notices at startup. **Not now** with **Don't show again for this version** suppresses that version's notification; manual updates remain available.

This repository contains distribution files and public documentation. Game development source and Git history are not stored here. GitHub's automatic Source code archives contain only this downloads repository's documentation.
